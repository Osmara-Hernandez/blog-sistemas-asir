Consumo de API GNews con PHP

16 abril 2026

En este proyecto se ha integrado una API externa para mostrar noticias tecnológicas en la web. Para ello se ha utilizado la API de GNews, gestionando la comunicación mediante PHP para evitar problemas de CORS y mejorar la seguridad.

¿Qué es una API?

Una API (Application Programming Interface) permite que diferentes aplicaciones se comuniquen entre sí. En este caso, se utiliza para obtener noticias en tiempo real desde un servicio externo.

Problema del acceso directo desde JavaScript

Inicialmente se intentó consumir la API directamente desde el frontend, pero esto generaba errores debido a las políticas de seguridad del navegador (CORS).

Por este motivo, se decidió utilizar PHP como intermediario.

Uso de PHP como intermediario

Se creó un archivo noticias.php que realiza la petición a la API utilizando cURL. Este archivo se encarga de recibir los datos y devolverlos en formato JSON al frontend.

De esta forma, el navegador ya no accede directamente a la API externa, evitando errores de seguridad.

Procesamiento de los datos

Una vez recibida la respuesta en formato JSON, los datos se procesan en JavaScript para mostrarlos dinámicamente en la página web.

Cada noticia se representa mediante una tarjeta que incluye título, descripción y enlace a la fuente original.

Integración en la web

Las noticias se cargan automáticamente al acceder a la página mediante una llamada fetch() al archivo PHP.

Esto permite ofrecer contenido actualizado sin necesidad de modificar manualmente la web.

Conclusión

La integración de la API GNews ha permitido añadir contenido dinámico a la web, mejorando la funcionalidad del proyecto. Además, el uso de PHP como intermediario ha solucionado problemas de seguridad y ha permitido una arquitectura más profesional.

Formulario conectado a base de datos con PHP y MariaDB

17 abril 2026

En este proyecto se ha implementado un formulario de contacto funcional que permite enviar datos desde el frontend y almacenarlos en una base de datos MariaDB. Este proceso simula el funcionamiento real de aplicaciones web dinámicas.

Diseño del formulario

El formulario se ha desarrollado en HTML y permite al usuario introducir datos como nombre, correo electrónico y mensaje.

Estos datos son enviados mediante el método POST a un archivo PHP encargado de procesarlos.

Procesamiento con PHP

Se ha creado un archivo procesar.php que recibe los datos del formulario y los prepara para su almacenamiento en la base de datos.

PHP actúa como intermediario entre el usuario y la base de datos, validando y gestionando la información recibida.

Creación de la base de datos

Se ha utilizado MariaDB para almacenar los mensajes enviados por los usuarios. Se creó una base de datos con una tabla que incluye los campos necesarios: nombre, email y mensaje.

Esta estructura permite guardar de forma organizada la información recibida desde el formulario.

Inserción de datos

Cuando el usuario envía el formulario, PHP ejecuta una consulta SQL que inserta los datos en la base de datos.

De esta forma se comprueba que la información se almacena correctamente.

Conclusión

La integración del formulario con PHP y MariaDB permite gestionar datos de usuarios de forma dinámica. Este proceso representa una funcionalidad esencial en aplicaciones web reales, combinando frontend y backend en un mismo sistema.

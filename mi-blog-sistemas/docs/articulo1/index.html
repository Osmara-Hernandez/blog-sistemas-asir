Configuración de servidor Ubuntu para despliegue web

15 abril 2026

En este proyecto se ha configurado un servidor Ubuntu dentro de una máquina virtual con el objetivo de desplegar una página web funcional. Este entorno simula un sistema real de producción, integrando tanto frontend como backend.

Creación de la máquina virtual

Se ha utilizado VirtualBox para crear una máquina virtual con Ubuntu como sistema operativo. Esta máquina actúa como servidor independiente dentro de la red local.

El uso de virtualización permite trabajar en un entorno aislado, facilitando pruebas sin afectar al sistema principal.

Configuración de red en modo puente

Para permitir el acceso desde otros dispositivos, la máquina virtual se configuró en modo puente. De esta forma, el servidor obtiene una dirección IP dentro de la misma red local.

Esto permite acceder a la web desde otros equipos mediante una URL como:

http://192.168.x.x

Instalación del servidor web

Se ha instalado XAMPP, que incluye Apache, PHP y MariaDB. Esto permite disponer de un entorno completo para el desarrollo web.

Una vez iniciado Apache, se comprobó el correcto funcionamiento accediendo desde el navegador a la dirección IP del servidor.

Despliegue de la aplicación

La web desarrollada con Astro se ha compilado mediante el comando de build y posteriormente se ha copiado al directorio del servidor:

/opt/lampp/htdocs

Desde este punto, la aplicación es accesible desde cualquier dispositivo conectado a la red local.

Configuración de seguridad básica

Para mejorar la seguridad del sistema se han aplicado varias medidas:

  • Uso de firewall con UFW
  • Configuración de permisos en el sistema Linux
  • Uso de HTTPS mediante certificado autofirmado

Aunque se trata de un entorno de pruebas, estas medidas permiten simular un entorno real de producción.

Conclusión

La configuración del servidor ha permitido desplegar una aplicación web completa en un entorno real, integrando frontend, backend y base de datos. Este proceso refleja el funcionamiento de un sistema profesional y demuestra la capacidad de administrar servicios en un entorno Linux.

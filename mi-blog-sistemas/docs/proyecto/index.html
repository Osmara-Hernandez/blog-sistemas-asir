Proyecto ASIR

Desarrollo y despliegue de una aplicación web completa

Este proyecto consiste en el desarrollo de una aplicación web completa, incluyendo frontend, backend y base de datos, desplegada en un servidor Ubuntu en entorno real mediante máquina virtual.

Ver código en GitHub

Objetivos del proyecto

El objetivo principal ha sido desarrollar una web funcional que simule un entorno real de producción, integrando distintas tecnologías vistas durante el ciclo ASIR.

  • Desarrollar una web con Astro
  • Implementar backend con PHP
  • Gestionar datos con MariaDB
  • Desplegar en servidor Ubuntu
  • Permitir acceso desde red local

Tecnologías utilizadas

Astro (Frontend)
PHP (Backend)
MariaDB (Base de datos)
Apache / XAMPP
Ubuntu Server
API GNews

Arquitectura del sistema

El sistema sigue una arquitectura cliente-servidor donde el navegador realiza peticiones al servidor Apache, que ejecuta scripts PHP para gestionar la lógica y comunicarse con la base de datos o servicios externos.

Usuario → Navegador → Apache → PHP → Base de datos / API

Funcionalidades implementadas

  • Blog con artículos técnicos
  • Consumo de API externa (GNews)
  • Formulario conectado a base de datos
  • Modo oscuro
  • Diseño responsive

Despliegue del sistema

La aplicación se ha desplegado en un servidor Ubuntu dentro de una máquina virtual. Se ha configurado la red en modo puente para permitir el acceso desde otros dispositivos mediante una dirección IP local.

El servidor utiliza Apache (XAMPP) para servir la web, permitiendo la ejecución de código PHP y la conexión con la base de datos MariaDB.

Seguridad y configuración

  • Firewall configurado con UFW
  • Certificado HTTPS autofirmado
  • Gestión de permisos en Linux
  • Control de accesos al servidor

Conclusión

Este proyecto demuestra la integración de múltiples tecnologías para crear una aplicación web funcional en un entorno real. Se han aplicado conocimientos de administración de sistemas, redes y desarrollo web, replicando un escenario profesional de despliegue.
